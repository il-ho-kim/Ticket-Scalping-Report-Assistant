# PRD v0.2 — "암표 신고 준비 도우미"로 피벗

## 1. 문제

온라인 암표신고센터로 신고할 때

- 공연인지 스포츠인지에 따라 신고 사이트가 달라, 어디로 신고해야 하는지부터 헷갈린다.
- 발견한 거래가 신고 대상인지 판단하기 어렵다. [재판매 목적으로 시스템을 우회 또는 방해하여 입장권을 구매하는 부정구매와 입장권 판매자의 동의를 받지 않고 상습 또는 영업으로 웃돈을 얹어 입장권을 판매·알선하는 부정판매] 중 어디에 해당하는지 구분하기도 어렵다.
- 증빙 정리가 번거롭다. 중고거래·SNS 게시글이 삭제되기 전에 캡처해야 하고, 게시 URL, 게시 일시, 판매가와 정가, 판매자 계정 정보를 따로 정리해야 한다.
- 공연·경기명, 일시, 장소, 좌석, 정가 대비 판매가, 거래 플랫폼 등을 빠짐없이 서술하는 것이 귀찮다.

## 2. 고객

- 티켓팅에 실패한 뒤 중고거래·SNS에서 웃돈 거래 게시글을 발견한 공연·스포츠 팬
- 암표 게시글을 발견해 삭제되기 전에 즉시 신고하려는 시민
- 신고 대상 여부 판단과 신고 내용 작성에 부담을 느끼는 신고자
- 신고포상금에 관심이 있어 요건을 갖춘 신고를 하고 싶은 신고자

## 3. 불편의 크기

티켓팅마다 겪는 암표상들의 만행.

- 암표방지법 시행 후(2026.8.28\~9.16) 신고가 하루 평균 245.4건
- 최근 1년(2025.9\~2026.8) 누적 공연 암표 신고는 7,639건에 달한다.

## 4. 핵심 가치

암표 거래를 발견했을 때 필요한 판단·증빙·서술의 부담을 줄여, 필요한 정보가 갖춰진 암표 신고를 올바른 창구에 빠르게 접수할 수 있게 한다.

- **판단 부담 감소**: 공연·스포츠 분야와 신고 창구를 안내하고, 부정판매·부정구매 해당 가능성을 쉽게 확인하게 한다.
- **증빙 부담 감소**: 게시글 캡처, URL, 게시·캡처 일시, 정가·판매가를 한 번에 정리하고, 개인정보 등 불필요한 부분을 가리는 편집을 돕는다.
- **서술 부담 감소**: 공연·경기 정보와 거래 정보를 바탕으로 신고 내용 초안을 만들어, 신고 양식에 바로 옮겨 붙일 수 있게 한다.

## 5. 핵심 흐름 다섯 단계

1. 사용자가 게시글 캡처를 올린다
2. 사용자가 자동으로 채워진 정보를 확인한다
3. 사용자가 신고 초안을 복사한다
4. 사용자가 공식 사이트로 이동한다
5. 사용자가 자동으로 값을 채워 제출한다

## 6. 화면 세 개

- **화면 1 · 증빙입력**
  - 담당 단계: 1, 2
  - 보이는 것: 캡처 업로드 박스, 자동 인식된 정보(자동/직접입력 표시), 개인정보 가리기 도구
  - [신고 초안 만들기] → 화면 2
- **화면 2 · 신고초안**
  - 담당 단계: 3
  - 보이는 것: 항목별 요약 카드(복사 버튼), 신고 문구 초안 텍스트박스, 전체 복사 버튼
  - [공식 사이트로 이동] → 화면 3
- **화면 3 · 사이트이동**
  - 담당 단계: 4, 5
  - 보이는 것: 공식 사이트 열기 버튼, 북마크릿(자동 채우기) 버튼, 항목 대응표
  - [사이트 열기]/[북마크릿 클릭] → 서비스 밖(공식 사이트)

## 7. 안 할 것

- **로그인·회원가입**: 계정 생성, 프로필 관리, 소셜 기능
- **대리 제출**: 공식 신고 시스템에 자동으로 접수하는 기능. 본인 확인과 최종 제출은 신고자가 공식 사이트에서 직접 한다.
- **신고 후 처리**: 접수 결과, 처리 현황 조회, 과징금·포상금 진행 알림
- **판매자 추적**: 판매자 신원 조회, 계정 모니터링, 여러 게시글 수집 등 신고 범위를 넘어서는 정보 수집
- **위반 여부 확정**: 법적 판단이나 포상금 지급 가능성 보장. 판단 보조와 안내까지만 한다.
- **장기 보관**: 개인 신고 이력, 원본 캡처 아카이브
