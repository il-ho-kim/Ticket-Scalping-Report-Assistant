# PRD v1.0 — 암표 신고 준비 도우미

## 1. 문제
- 공연·스포츠마다 신고 창구가 달라 어디에 신고할지부터 헷갈린다.
- 발견한 거래가 부정구매(시스템 우회 구매)인지 부정판매(상습·영업 웃돈 판매·알선)인지, 신고 대상인지 판단하기 어렵다.
- 게시글이 지워지기 전에 캡처하고 URL·게시 일시·정가·판매가·판매자를 따로 정리해 신고서에 빠짐없이 적기가 번거롭다.

## 2. 고객
웃돈 거래 게시글을 발견한 공연·스포츠 팬과 시민. 그중 판단·작성에 부담을 느끼거나, 포상금 요건을 갖춘 신고를 하고 싶은 신고자.

## 3. 불편의 크기
암표방지법 시행 후(2026.8.28\~9.16) 신고가 하루 평균 245.4건이고, 최근 1년(2025.9\~2026.8) 누적 공연 암표 신고는 7,639건이다.

## 4. 핵심 가치
판단·증빙·서술 부담을 줄여, 필요한 정보가 갖춰진 신고를 올바른 창구에 빠르게 접수하게 한다.

## 5. 핵심 흐름
시작 → 분야 선택 → 부정구매·부정판매 판단 → 캡처·글로 증빙 채우기 → 초안 복사 → 공식 사이트에서 자동 채우기 후 직접 제출

## 6. 지금 있는 것
- 로그인 없이 휴대폰 브라우저에서 6단계로 신고를 준비한다.
- 공연 분야를 고르면 한국콘텐츠진흥원 온라인 암표 신고센터를 안내한다.
- 질문 세 개에 답하면 부정구매·부정판매 가능성을 참고용으로 알려준다.
- 캡처를 최대 5장 올리거나 게시글을 붙여넣으면 공연명·일시·장소·좌석·가격·플랫폼·예매처·판매자·게시일시를 자동으로 채운다.
- 캡처 글자 인식은 기기 안에서 하고, 캡처를 밖으로 보내지 않는다.
- [자동으로 읽기] 한 번으로 캡처 읽기, 판매글 찾기, 공식 정보 확인, 빈 필수 항목 안내까지 이어서 한다.
- 티켓베이 캡처로 같은 판매글을 찾아 게시글 주소를 넣고, 붙여넣은 주소가 캡처와 같은 글인지 확인한다.
- 공연예술통합전산망(KOPIS) 공식 정보와 비교해 정가·공연장·예매처 등을 바로잡는다.
- 칸마다 값의 출처(캡처에서 읽음, 판매글에서 확인, 공식 정보로 고침, 직접입력)를 표시하고, 사용자가 고친 칸은 덮어쓰지 않는다.
- 캡처 속 얼굴·전화번호를 손가락으로 칠해 가린다.
- 항목별 요약과 신고 문구 초안을 만들고, 항목별·전체 복사를 한다.
- 북마크릿으로 공식 신고 양식에 준비한 내용을 채우고, 안 채워질 때 쓸 항목 대응표를 보여준다.

## 7. 자동 채우기 원칙
자동으로 채운 값은 모두 확인·수정할 수 있다. 공식 정보와 다른 값은 차이를 먼저 보여주고, 인식이 막히면 붙여넣은 글로 다시 시도한다.

## 8. 북마크릿 원칙
성명·휴대폰·이메일·본인인증·개인정보 동의는 채우지 않고, 제출 버튼도 누르지 않는다. 캡처는 신고자가 증빙자료로 직접 첨부한다.

## 9. 현재 범위와 제약
- 스포츠 분야는 준비 중이라 공연만 끝까지 진행된다.
- 판매글 찾기는 티켓베이만 되고, 판매가 끝났거나 삭제된 글은 찾지 못한다.
- KOPIS 확인과 판매글 찾기는 서버 함수(Vercel)가 있어야 하고, 없으면 그 기능만 꺼진다.
- 입력값과 캡처는 저장하지 않아 창을 닫으면 사라진다.

## 10. 안 할 것
- **로그인·회원가입**, **신고 후 처리 조회**, **장기 보관**(신고 이력·캡처 아카이브)
- **대리 제출**: 본인인증과 최종 제출은 신고자가 공식 사이트에서 직접 한다.
- **판매자 추적**: 판매글 찾기는 신고할 글 한 건을 특정하는 데만 쓰고, 다른 글 수집·판매자 추적·조회 결과 저장은 하지 않는다.
- **위반 여부 확정**: 법적 판단이나 포상금 지급을 보장하지 않고, 판단 보조와 안내까지만 한다.

## 11. 비즈니스 모델
공익 목적의 서비스이므로 이용료를 받지 않는다. 운영비는 제작자 후원(외부 후원 링크)과 최소한의 배너 광고로 충당하고, 광고는 신고 흐름을 방해하지 않는 자리에만 둔다.
